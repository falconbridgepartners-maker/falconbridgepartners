# Assets for generated link-preview images

Used only by `app/og/[kind]/[slug]/route.tsx`, which draws the 1200 × 630 image a page shows when its link is shared.

- `arimo-latin-400-normal.woff`, `arimo-latin-700-normal.woff`: Arimo, metric-compatible with Arial (the site's text face). © The Arimo Project Authors. SIL Open Font License 1.1.
- `gelasio-latin-400-italic.woff`: Gelasio Italic, metric-compatible with Georgia (the site's accent face). © The Gelasio Project Authors. SIL Open Font License 1.1.
- `logo.png`: the FalconBridge Partners logo, copied from `src/assets/logos/logo.png`.

The fonts come from the `@fontsource/arimo` and `@fontsource/gelasio` packages (version 5.3.0). The licence text is at https://openfontlicense.org.
